## 3. T7 шаг 3б

**(а) умолчание `on`.** Переворот дал 70 новых падений — все разобраны:
- `price_turns.json` переснят: **ровно** прежняя база + 5 объявленных отличий разбора (`price_turns_parse_on.json` слит и
  удалён, `PARSE_ON_PLANNED` снят) — других изменений базы нет.
- `price_turns_on.json` (понимание on × разбор on, LLM недоступна) — это **комбинация прода**, раньше эталоном не
  покрытая; дифф — текущее поведение прода при сбое LLM, а не изменение. По смыслу: лучше 2 («ферритин, глюкоза,
  холестерин» — в вариантах есть «Холестерол 225»; «ттг, т4 свободный» на кнопку — варианты ТТГ и «Не распознал: т4»
  вместо «не нашёл»); спорно 1 («оак, оам» — варианты «ОАК полный / без формулы» вместо «ОАК базовый / полный», чужой
  единичной цены нет); хуже, известное 1 («ОАК ОАМ ФЕРРИТИН ГЛЮКОЗА» — семья ОАК, xfail шага 3а); **хуже, находки 2** —
  см. «Решения» п. 1–2.
- Тесты «так под off» переведены на разбор: `test_price_one_or_many_class` (наборы `default` / `deploy`, `deploy_parse`
  — псевдоним деплоя; отметки off сняты), `test_price_list_class`, `test_basket_select`, `test_messenger_services`,
  `test_turn_understanding`, `test_l14_two_turn_consumers`.

**(б) снять off/shadow.** Сняты ключ `turn_parse` (в `config.ini` прода безвреден — не читается; убрать можно в любой
сборке), `turn_parse.mode()`, тень (`read_only_memory`, `peek`, `drain`, статус `late`; на конце хода —
`cancel_unfinished()`), `shadow` у генератора фраз, ветки режима в понимании хода, ветки корзины правил, жившие только под
`off` (`failure_variants` — всегда). Механизм тени `choice` / `llm_runtime` оставлен — его использует `pending_reply`.
Эталоны не менялись. `test_turn_parse_shadow.py` → `test_turn_parse_slot.py`.

**(в) K1–K3 — не сняты, и вот почему.** После (б) у них остались вызывающие, и все — там, где разбор не годится для
действия: `empty`, `too_many`, `error`, или вход читателя — не реплика хода (дозаполнение, контекст прошлого хода, цена
попутно в записи, вызов вне хода):
- K1 защиты `price_list_services` («одно название покрывает», «сплошной — только распознанный») — понимание правил
  (`understand_price_turn`: ленивый путь при `acting_for = None` и при `single`), срок правилами
  (`_readiness_select`), согласие разрезов (`_agreement`, только при `parse_agree_telemetry = on`);
- K2 `_multi_price_items` / `_resolve_multi_price_items` — корзина правил (`prices._multi_price_payload` при
  `acting_for = None`), подбор анализов (`lab_tests`, сегментация — S2-соседство), генератор (в) — не трогать;

Снятие изменило бы ответы именно на этих путях — по правилу хэндоффа оставлены. Снять их можно только вместе с решением,
что делать на `too_many` / `error` / не-реплике без правил (см. «Решения» п. 3).

- **§4а.2 чистка** — сделано (`b3ca61c`). `_parse_strong_selection` оставлен: один вызывающий (`_parse_strong_answer`),

- **§4а.3 вариант B называет чужую строку** — корень: словоформа («сифилис» целиком только в чужой строке, в верной —
  «сифилиса»; поэтому слово и «самое редкое»). Фикс под выключателем (по умолчанию off), встречный свип 398 названий
  мини-прайса: изменилось 6, потерь попаданий и первых строк 0 (подробно — журнал BUG-2026-10-16-VARIANT-B-WORDFORM).
  Две более широкие попытки (74–90 изменений с лишними названиями) отброшены.
- **§4а.4 находка агента (только описание):** после цены, выбранной LLM, в сессии нет `service_name` — «а сколько стоит
  по омс?» идёт не к судье П2, а в выбор строки без кандидатов: «Уточните» (П2 соблюдён) за два вызова LLM. Это класс
  «контекст = показанное» (L-14, `shown_context`, `[MESSENGER_ROUTER] context_shown`, по умолчанию off — уже в ветке):
  под `on` выбор LLM пишется в `service_name`, и второй ход пошёл бы к судье П2 за один вызов. Офлайн воспроизвести не
  удалось: в мини-прайсе нет строки «УЗИ щитовидной железы» (первый ход — «не нашёл»). Проверить на живом прайсе.

## 5. Решения на проверку владельцем

1. **Регрессия шага 3а (не на проде):** «а на ферритин нужна запись?» при недоступной LLM — разрез данными МИС
   (`fallback_split`) режет на «а» / «Ферритин» / «запись», понимание переклеивает walk-in в цену: корзина с ценами
   аллергенов («По услуге «а»…»). На проде (`4040d99`) шага 3а нет — там walk-in. Слова «а», «запись» есть в названиях
   прайса, поэтому промежутки «в прайсе» и гард П2 не срабатывает. `fallback_split` — у ведущего; эталон
   `price_turns_on.json::walkin_named` записан с пометкой «НАХОДКА». Варианты: промежуток из слов обвязки (`_WRAPPER`,
   `_SPEECH_WRAPPER`) — не позиция; или разрез данными — только при ≥2 сильных окнах.
2. **Частица «а» в позиции:** «а ферритин, глюкоза?» при сбое LLM — позиция «а ферритин» слабая («похожая услуга:
   Ферритин» вместо цены): фраза разреза снимает с краёв только `_WRAPPER`, «а» туда не входит. Правка — снимать и
   речевую обвязку (`_SPEECH_WRAPPER`, как `turn_understanding._bare_phrase`), но она меняет варианты для LLM разбора —
   нужен живой замер.
3. **`too_many` / `error` / не-реплика** — путь правил оставлен «как было» (K1–K3 живы). Снять их — только с решением,
   что отвечать там без правил (уточнение? варианты?).
4. **`choose_basket = off`** после снятия `off` разбора решает только, зовут ли LLM для строк слабых позиций; прежней
   корзины правил («Глюкоза в моче» второй строкой) больше нет ни при каком значении. Оставить выключатель или снять?
5. **`variant_b_wordforms = on`** — включать? Свип только на мини-прайсе; перед включением — встречный свип на живом
   прайсе (`sweep` в журнале воспроизводим: «сколько стоит» + название без скобок, пул как в ходе).
6. **«оак, оам» при сбое LLM** (спорно): варианты кода «ОАК полный 550 / без формулы 250» без базового «ОАК (Le, Er, Hb,
   СОЭ) 390». Чужой единичной цены нет, но базовая строка — самая частая. На проде с синонимами МИС «оак» — сильная
   позиция; в мини-проде синонимов нет. Проверить на живом прайсе.
7. **`config.ini` прода:** ключ `turn_parse` больше не читается — убрать в любой сборке.
8. **Гейт на Mac** (§2): особенно тесты живого каталога, которые неявно шли под `off`.
