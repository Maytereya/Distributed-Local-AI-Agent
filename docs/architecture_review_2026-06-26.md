# Архитектурный разбор `messengers_router` — 2026-06-26

> **Что это:** полный аудит архитектуры (латентность/asyncio, NLU+RAG, multi-item,
> мёртвый код, доки, готовность к внешнему ревью) с risk-грейдом каждой рекомендации.
> Выполнен на HEAD `21cb8a1` (baseline-тег `baseline-2026-06-26`). Каждое утверждение
> привязано к файлу:строке. Дорожная карта — §7; она же трекается в сессиях работ.
> **FreeTalk (`src/localragagent/`) вне скоупа** — подсистема Владимира.

## 0. Рамка: что это за система

НЕ векторный RAG, а гибрид: детерминированный rule-first NLU (`legacy_v2`; правило
не-None короткозамыкает LLM) → структурный retrieval из API Наяки (каталог 3675 услуг,
врачи, /regions live) → лексический grounding → **детерминированные рендереры для
большинства меток** (schedule/price/doctor_info — без LLM вообще) → LLM только на
свободных путях. Сильные стороны: bug-log с класс-инвариантами, 1140 тестов, remote
eval (golden corpus + safety gate), resilience-таксономия (`resilience.py`),
output-security-guard (`scrub_internal_disclosure`), entity_grounder.

Главные риски НЕ в «плохом коде»: (а) LLM-путь без данных галлюцинирует (кейс
«больничный лист» 25.06 — бот уверенно соврал «не занимаемся»); (б) лексический
матчер не мостит синонимы (беговая дорожка со словарём); (в) два незавершённых
рефактора — orchestrator↔router и файлы-гиганты.

## 1. Латентность: где она есть и где её НЕТ

Async-домашка в основном сделана:
- sync `requests` к Наяке обёрнут в `asyncio.to_thread` (23 места) — loop не блокируется;
- параллелизм внутри хода: `router.py:1173` (верификация врача ∥ catalog-prefetch),
  `router.py:1330`, `services/doctors.py:291`, `services/prices.py:634`;
- `llm_runtime.py`: AsyncClient + `Semaphore(5)` + таймауты + `keep_alive=-1`;
- телеметрия УЖЕ встроена: `orchestrator.py:50` `stage_timings` (в `debug=true`),
  файловый лог промптов включается на лету: `touch /tmp/llm_prompts.enabled`
  (`llm_runtime.py:42-54`).

Реальные узкие места (по весу):
1. **Сама модель (~90%)**: `mistral-small3.2:24b-fp16` = 57GB на 3×RTX 4090 (24GB) —
   межкарточный обмен на каждый токен. Худший ход = classify + render = 2
   последовательных LLM-вызова. Рычаг — НЕ в коде: **квант q8_0 (~25GB, 2 карты)**
   или **q4_K_M (~14GB, 1 карта + `OLLAMA_NUM_PARALLEL=2-3`** — сейчас конкурентные
   пользователи сериализуются на уровне ollama). Проверка сдвига качества — remote
   eval до/после (идеальный black-box кейс). Отдельно (риск выше, только через eval):
   маленькая модель для классификатора (rule=None, JSON-метка — задача 4-8B).
2. **Последовательный fanout расписания** — `find_doctor_schedule` (филиалы × дни,
   замер 7.2с на Трубине). Это готовый план **Resilience Phase 2**
   (`docs/superpowers/plans/2026-06-06-resilience-degraded-mode-phase1.md`, раздел
   Phase-2 follow-ups). `asyncio.gather` + семафор 3-4 на medserver.
3. НЕ трогать: `deterministic_rule_decision` зовётся 2× за ход (`orchestrator.py:293`
   и внутри nlu_route) — это regex-микросекунды; чинить = риск ради нуля.

Порядок: сначала ИЗМЕРИТЬ (p50/p95 по stage_timings с прода за день) → квант → Phase 2.

## 2. NLU/RAG: 4 метрики + как слезть с беговой дорожки синонимов

| Метрика | Реализация | Оценка |
|---|---|---|
| Context recall | лексический матчер + курируемые алиасы (`_PRICE_SERVICE_ALIASES`) + гомоглифы + framing-стрипперы + синоним-fast-path (BUG-2026-06-23-01) | 🔴 слабейшее звено: несловарный синоним = промах (история: забор/взятие, электромиография/ЭМГ, сахар=глюкоза, коагулограмма — BUG-2026-06-02-09) |
| Context precision | distinctive-token guard (BUG-2026-06-09-04), анти-подмена УЗИ (BUG-2026-06-02-07) | 🟡 family_query отдаёт 47 строк на «забор крови» — шум |
| Faithfulness | детерминированные форматтеры без LLM; промпт «ТОЛЬКО буквальные значения»; entity_grounder; `scrub_internal_disclosure`; rich-critic (`renderer.py:905`) | 🟢 на data-путях; 🔴 дыра на путях БЕЗ данных: OTHER/неизвестная тема → LLM сочиняет («больничный лист») |
| Answer relevancy | clarify-гейты, pending-флоу, topic_registry | 🟢 |
| Измерение | eval меряет intent/handoff/slot_fill; faithfulness генерации НЕ меряет (только forbidden/required в critical) | 🟡 гэп |

**Трёхслойная воронка синонимов** (каждый слой включается ТОЛЬКО на промахе
предыдущего → нулевой риск для работающих кейсов):
1. Курируемая карта (есть) — «голова» частотных синонимов.
2. **Вариант B (одобрен владельцем)**: LLM-нормализация fallback-only — на
   `resolve → None` LLM переписывает формулировку в термин каталога → результат
   ОБЯЗАТЕЛЬНО верифицируется тем же лексическим resolve (LLM не может выдумать
   услугу). +1 LLM-вызов только на промахах.
3. Embedding-кандидаты: индекс 3675 `serviceName` (инфра ЕСТЬ:
   `agent_logic_1/embedding_filtration.py` + Chroma-контейнер на сервере) → top-K по
   косинусу → верификация distinctive-token-гардом → одна уверенная = ответ,
   несколько = честный уточняющий вопрос. Миллисекунды, без LLM. Валидировать
   ОФЛАЙН на парах из bug-log ДО включения.

Правило для новых слоёв: **никогда не доверять fallback напрямую — всегда
пере-проверять по каталогу; сомнение → уточняющий вопрос.**

**Дыра faithfulness вне RAG** (класс «больничный лист»): (а) статические интенты для
тем-фактов о клинике (образец — налоговая справка: `DOC_REQUEST_PATTERNS` →
детерминированный ответ); (б) промпт-гард «о правилах клиники вне Данных не
утверждать — предлагать оператора»; (в) faithfulness-пробы в eval («делаете ли МРТ
колена?» → честное нет, не выдумка).

## 3. «Корзина анализов» (BUG-B): диагноз и дизайн

Диагноз: механика есть (`_prices_helpers.py:2214`), но сплиттер режет ТОЛЬКО по
`, ; + / и` (`:2207`) — ни `\n`, ни маркеров списка; каждый фрагмент должен
зарезолвиться score≥100; <2 успешных → молча single-путь → пациент получает ответ
про ПЕРВЫЙ анализ. Реальный BUG-B список (30 позиций, CAPS, переносы, опечатки) не
делится вообще.

Дизайн (staged, каждый шаг fallback-only):
- **S1**: + `\n`, `•`, `-`-маркеры в сплиттер. Класс-тест на дословном BUG-B сообщении.
- **S2 (ключ)**: сегментация по каталогу для списков без разделителей — жадный
  longest-match n-грамм по токенам, где лексикон = сам каталог («ОБЩИЙ БЕЛОК» — 2
  токена, «ОАК» — 1). Гейт: PRICE/TEST_ASSIST + ≥3 кандидат-токенов + обычный
  resolve дал ≤1.
- **S3**: честный ответ — распознанные списком с ценами (+ сумма), нераспознанные
  ЯВНО («не распознал: …, уточните»).
- **S4 (опц.)**: LLM-экстракция названий в JSON для грязных списков → каждое
  верифицируется по каталогу.
- На каждую позицию — весь стек (алиасы/гомоглифы/синонимы/`strip_readiness_phrasing`).
