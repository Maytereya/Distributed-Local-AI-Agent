# Диагностика адресных путей `messengers_router` (2026-06-08)

> **Зачем:** адреса фигурируют во многих путях (по специальности, анализы, процедуры,
> часы работы…), и за время было много точечных правок. После регион-`city` фикса
> (BUG-2026-06-08-02 / триаж BUG-A) проверяем, что пути **НЕ путаются** и каждый отдаёт
> свой корректный набор адресов.

## Карта адресных путей (`services/addresses.py::address_info`, порядок проверки)

| # | Путь | Триггер | Источник адресов |
|---|------|---------|------------------|
| 1 | fixed-equipment | флюорограф/маммограф | хардкод (Ленина 5) |
| 2 | priceUnits care-setting | service + (appointment/lookup), `procedure_flag=None`, **НЕ запись по специальности** | priceUnits — место оказания процедуры |
| 3 | procedure-index | «где делают X» | `doctor_prices` индекс |
| 4 | regions-flag-filter | анализы/УЗИ/ЭКГ (`procedure_flag`) | `/regions` флаги `usi`/`analysis`/`ecg` |
| 5 | doctor-capable | запись по специальности (приём врача) | `/regions` ∩ врачи этой спец-ти |
| 6 | doctors-cache fallback | `/regions` офлайн | кэш врачей (specialty-filtered) |

Вне `address_info`: appointment-оффер филиалов врача (из его расписания), часы работы филиала (ADDRESS).

Город филиала выводится из иерархии `parent` (`_regions._inject_region_cities`, BUG-2026-06-08-02) —
новый прод-бэкенд `medserver-egisz` не отдаёт поле `city`.

## Метод
- **Локально:** класс-инвариант-тесты на прод-подобном датасете (parent-иерархия без `city`,
  разные флаги, врачи разных спец-тей) → все типы запросов → каждый путь отдаёт свой набор.
- **Прод:** in-process probe (в обход nginx-403) на живых `/regions` + врачах + прайсе.

## Выводы
- **Опасного СМЕШЕНИЯ адресов НЕТ:** анализ/УЗИ/ЭКГ дают разные флаг-наборы (31/4/25, не
  одинаковые); лаб-точка «Гагарина 64» видна для анализов и **скрыта** для записи к врачу;
  процедуры идут priceUnits-путём; Тольятти/спутники исключены по городу из `parent`.
- **Найден и починен 1 баг СУЖЕНИЯ** (BUG-2026-06-08-03): запись по специальности
  перехватывалась priceUnits care-setting → сужалась до одного «Ленина 5» (дезинформация —
  будто врачи только там). Теперь → doctor-capable (ВСЕ филиалы этой специальности).
