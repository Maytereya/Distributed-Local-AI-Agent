### 1.1 Утечка кодов уточнения (`llm_primary`) — BUG-2026-10-20-CLARIFY-CODE-LEAK

- **Подтверждено через эндпоинт:** под `llm_primary` на «хочу записаться» бот отвечал буквально **«slot_request»**, на
  «мне бы узнать насчёт анализов и врача», при мусорном ответе и **при сбое LLM** — **«intent_disambiguation»**. Корень:
  поле `clarify_reason` перегружено (правила кладут туда готовый текст, разбор LLM — код), а `orchestrator.clarify_gate`
  печатал его как есть; перевод кода в вопрос (`recovery_policy._structured_clarify_text`) был, но до него ход не доходил.
- **Фикс:** `recovery_policy.patient_clarify_text` — текст правил как есть, код или пусто — вопрос по нему; `clarify_gate`
  берёт текст оттуда. Попутно грамматика: «вам нужна подбор анализов?» → «вас интересует подбор анализов?».
- **Тест класса:** `tests/test_clarify_code_leak_class.py` (25): `llm_primary` × {нет слотов, низкая уверенность, LLM сама
  вернула код, мусор, сбой} × 4 реплики — ни один ответ не содержит кода; текст правил (больничный) — как есть.
- **Стенд `down`** (`sw_llm_primary_clarify`, 6 диалогов / 7 ходов, `--cfg MR_NLU_ENGINE=llm_primary`): `release` — 5 ответов
  «intent_disambiguation», после фикса — 0, вместо них вопросы. Под `legacy_v2` кодов нет — ответы прода прежние.
- **Находка для хода (и), не исправлялась:** при недоступной LLM `llm_primary` **не имеет запасного пути правил** — даже
  «сколько стоит ферритин» получает «Уточните, что именно вам нужно: 1. подбор анализов 2. стоимость услуги», тогда как
  `legacy_v2` в той же ситуации отвечает ценой правил. Это отдельное условие включения (§4, вопрос 2).

### 1.2 «ферритин первый раз и глюкоза» → только глюкоза — BUG-2026-10-20-BASKET-WEAK-PHRASE-GUARD

- **Корень (мир `mini_prod`, набор деплоя, оракул разбора режет верно):** окна разбора на проде выключены (решение 16.10),
  фраза разбора «ферритин первый раз» — слабая; в `_prices_helpers.phrase_price_items` словарный гард П2
  (`query_has_unsatisfiable_qualifier`) считает «первый», «раз» уточнением, которого нет в прайсе, — «Не распознал» **без
  вызова LLM**. Тот же класс, что корень (1) п. 1 кикоффа (путь одной услуги, локальная ветка `claude/candidates-by-meaning`),
  — на пути корзины. Вариант «ферритин первый раз и глюкоза сколько стоят» давал «Уточните название» целиком.
- **Фикс (под `basket_weak_phrase_judge = on`):** внутри слабой фразы ровно одно сильное по данным МИС окно 1–3 слова
  (`_turn_phrases.strong_inside`, механика окон разбора, без словарей) — позиция идёт на суд LLM корзины тем же механизмом,
  что сильная фраза с условием (`judge` / `condition`, правило 5 промпта корзины): разговор — цена, условие («по омс») —
  «Не распознал» словами пациента, сбой LLM — «Не распознал» (П2). Два названия во фразе, нет слов вокруг — как было.
- **Тест класса:** `tests/test_basket_weak_phrase_judge_class.py` (9): три формулировки «первый раз» → цены ферритина и
  глюкозы (под off — без ферритина); «по омс» — без цены; сбой выбора строк — без цены; списки без слов вне прайса — без
  изменений.
- **Стенд `down`** (`sw_basket_weak_phrase_judge`, 6): off против on — 0 различий (без LLM суд не проходит — как было).

## 4. Решения на проверку владельцем

1. **Фикс утечки кодов — без выключателя.** Он меняет ответы только под `llm_primary` (на проде выключен), под `legacy_v2`
   кодов нет. Согласны слить в деплой 11 без выключателя?
2. **`llm_primary` при сбое LLM — без запасного пути правил.** Сейчас на любую реплику (даже «сколько стоит ферритин») —
   «что именно вам нужно: …», у `legacy_v2` — ответ правил. Предложение: условие включения хода (и) — при `unavailable` /
   `invalid` разбора LLM решать правилами (как `legacy_v2`), с отметкой в телеметрии; записать в критерии реплей-карточки.
3. **`basket_weak_phrase_judge` и п. 1 кикоффа** — один класс («гард П2 — повод спросить LLM») на двух путях. Предложение:
   держать раздельно до двух карточек, затем один выключатель или снятие обоих вместе.
4. **Окна разбора или этот фикс.** Под `parse_fragment_windows = on` похожие реплики уже идут через сильную фразу с условием
   (`strong_phrase_guard`), но только если LLM разбора выберет «ферритин», а не «ферритин первый раз». Фикс корзины не
   зависит от выбора разбора — предлагаю его, окна не включать (решение 16.10 в силе).
5. **Ожидания наборов** (`expect`) — по смыслу записей журнала; часть (например, «ферритин с выездом на дом») — догадка о
   том, что правильно для клиники. Проверить на разметке до карточки.
