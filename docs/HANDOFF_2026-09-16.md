## 2. Очередь работ

### №1 — Гард П2 гасит корзины `[ПРИОРИТЕТ, нужно решение владельца]`

`BUG-2026-09-07-GUARD-OVER-BLOCK`. Полностью распознанная корзина мульти-расчёта
возвращает `None`: «ферритин, глюкоза, холестерин» → 3 позиции распознаны,
нераспознанных нет, ответа нет.

**Новое доказательство масштаба (16.09):** разбор 7 месяцев переписки показал
**29 промахов-корзин** из 507 ценовых реплик. Это САМЫЙ ЧАСТЫЙ класс промахов в
живом трафике: «Общий анализ крови с лейкоформулой, временем свертывания,
тромбоциты и глюкоза», «Кровь: АЛТ, АСТ, ГГТП, цистатин С». Пациент видит не
ошибку, а молчание.

Блокирует калькулятор анализов из ТЗ. Требуется проектный выбор: как отличить
синоним услуги («холестерин» → Липидограмма) от уточнения НА услуге («приём
терапевта по ОМС»). Наивный фикс возвращает исходный баг П2.

### №2 — «кровь на сахар» отдаёт аллергопанель

`BUG-2026-09-07-PREFIX-COLLISION`. «кровь на сахар» → «Свекла сахарная (F227)»
650 руб. вместо Глюкозы 190. Три другие формулировки клиника починила данными.

Держит анти-перехват: в остатке остаётся «кровь», а его нет в речевой обвязке.
**Добавлять «кровь» в обвязку НЕЛЬЗЯ** — оно значимо в названиях («Группа
крови», «Кровь на ВИЧ»). Правильный путь: засчитывать в остатке слова-
биоматериалы по словарю `biomatNames` МИС (заполнен у 98%). Данные из МИС, не
список в коде. Мешает то, что `split_biomaterial_tail` снимает ХВОСТ, а тут
«кровь на» стоит спереди.

### №3 — Семейство по широкому слову даёт свалку

## 4. Чего НЕ делать

- Не искать причину прод-сбоя в коде по одной вилке дат. Сначала `debug=True` →
  `route_error`, потом `main_model.txt`, потом ollama.
- Не приравнивать «мазок» и «посев» — 290-510 руб. против 1120.
- Не добавлять ручных синонимов услуг: только из МИС.
- Не снимать гард family-mode для витаминов целиком — сломает точное попадание
  «витамин Д».
- Не ослаблять eval-кейс, если бот ответил не по существу. Кейс по вульвоскопии
  оставлен красным намеренно: бот объясняет, ЧТО это, вместо того как
  подготовиться. Это разброс качества, а не хрупкость формулировки.
- Не вписывать в МИС опечатки пациентов («капрограмма», «оталорингологу») — это
  наша сторона, нечёткий матч и LLM-нормализатор.
