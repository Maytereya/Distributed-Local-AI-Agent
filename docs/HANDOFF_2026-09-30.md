## 6. Ошибки этой сессии — чтобы не повторить

- **План для шлюза проверял чтением — и нашёл 22 дефекта; исполнение на их
  репозитории нашло ещё 8.** План с кодом для чужой команды — только после прогона
  на их реальном репо и их гейте (клон, их `requirements.txt`, настоящий Postgres).
- **Тест класса «нажатие не вызывает догадку каталога» был зелёным без сети при
  живом баге:** путь до подтверждения каталогом требует сети/словаря. Закреплять
  поведенческим тестом, который воспроизводится в гейте (walk-in).
- **Первая версия теста «отказ по специалисту» строила инвариант на карте
  канонизации** и ложно требовала снять челюстно-лицевого хирурга. Источник правды о
  том, кто есть в клинике СЕЙЧАС, — живой справочник, не карта.
- **Сравнение через `| tee` отчиталось exit 0 при падении скрипта** — ловушка
  «`$?` после пайпа» из CLAUDE.md в новом месте. Писать вывод в файл без пайпа.
- **Локальные живые прогоны зависят от `config.ini` и от сети** (VPN рвётся):
  любое расхождение с продом сначала повторить, потом делать выводы.
