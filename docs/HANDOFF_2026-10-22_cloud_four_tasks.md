  атрибут `MR_<КЛЮЧ>`; образец — `catalog_confirm_llm`). Включает владелец после карточки стенда на Mac.
- **Храповик правил** (`tests/test_rules_ratchet.py`): новая регулярка или список слов уровня модуля (≥5 строк) — только со снятием
  другого в том же коммите; упал счёт — опустить потолок в том же коммите.
- **LLM — через `messengers_router/choice.py` (`choose()`)**; новый промпт — в двух локациях (`messengers_router/prompts/choose_<x>.txt`
  и `app_data/prompts/mr_choose_<x>.txt`, тексты совпадают).
- **Тесты — на КЛАСС**, подделка LLM настоящего типа; без данных МИС — в `tests/hermetic_files.txt` (тогда идут в CI); сеть в тестах закрыта.

- **Смена сигнатуры** — греп вызывающих и подмен (`monkeypatch.setattr(... , fake)`) по всему репо: `messengers_router tests evalbench scripts`.
- **Гейт в облаке:** `ruff check messengers_router tests` = 0 и полный `pytest -q -p no:cacheprovider -n auto`. Без срезов МИС падают
  ~230–260 тестов окружения (врачи, прайс, каталог) — **до первой правки сохранить поимённый список упавших, после каждого коммита —
  сравнить**: новых быть не должно (`pytest ... -rf 2>&1 | grep ^FAILED | sort > /tmp/fail_before.txt`, затем `comm -13`). Коммит —
  только при ruff 0 и без новых падений. Эталоны `tests/golden/*.json` под off не меняются.
