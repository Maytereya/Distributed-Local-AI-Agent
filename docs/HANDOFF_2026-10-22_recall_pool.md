# Recall@pool пути цены — замер по пулу из хода (22.10)

Ветка `claude/2026-10-22-recall-pool` от `release` = `389ffd4` (прод, деплой 15). Коммиты: `c38e7ed` (запись пула в
журнал хода), `6883d19` (детектор и раздел карточки). Без реплик пациентов: только id вопросов набора и счётчики.

## Что сделано

- **Запись, не логика.** `_price_select_llm._ask` — единственная точка вызова `choose()` выбора строки прайса — пишет в
  строку хода поле `price_pool`: `[{"r": круг, "n": размер, "ids": [serviceId…]}]` (`turn_telemetry.note_price_pool`).
  Круг 1 — пул по реплике, круг 2 — по терминам LLM. Сборка и выбор не тронуты, ветки `by_meaning` тоже: с веткой
  снятия выключателей (`claude/2026-10-22-switch-removal`) пересечений по строкам нет.
- **Детектор** `evalbench.detectors.pool_recall`: пул хода ∩ разметка цен (`labels/price_allowed.jsonl`, core ∪ ok).
  Одна услуга — 0/1, список (`multi`) — доля услуг core в пуле. Нет записи пула (LLM строку не выбирала) — отдельный
  счётчик, не 0%. Вне замера `not_price`, `context_dependent`, `absent`.
- **Срезы:** «слово в словаре клиники» (в реплике есть ключ `serviceSynonyms` среза мира — `ClinicSynonyms`, считается по
  данным, не кодом бота) / «вне словаря» / «список услуг» (`multi`) / «всего». «Прочее» вынесено в «без пула»: вопрос
  размечен, но выбор строки LLM на нём не звался (сильная фраза, корзина, не цена).
- **Карточка** (`python -m evalbench.card A B`): раздел «Recall@pool (цена)» — 1-й круг / с 2-м, вопросов с пулом /
  размечено, размер пула 1-го круга (среднее / p90), вызовов 2-го круга; при двух прогонах — id вопросов, выпавших из
  пула и вошедших в него, по кругам.
- **Тесты на класс:** `tests/test_price_pool_record_class.py` (через эндпоинт, оба круга: запись = ровно то, что видела
  LLM; с выключенной записью ответ, пулы и решения хода те же; телеметрия off — записи нет) и синтетика детектора,
  среза и сравнения в `tests/test_evalbench.py`.
- **Гейт** на каждом коммите: ruff 0, pytest `-n auto` 0 (5949 passed / 13 xfailed на `6883d19`).

### Как читать

- **Покрыта только часть размеченных вопросов: 113 из 255 на dev.** Без пула 142:
  - 73 — корзина: их ведёт выбор корзины (`choose` с задачей `price_basket`), а не `select_price_rows` (72 списка +
    1 «в словаре»);
  - 16 — сильная фраза: код решает без LLM (13 «в словаре», 3 «вне»);
  - 47 — ход ушёл не в цену (оффер, адрес, TEST_ASSIST, запись…; 34 из них «вне словаря»);
  - 6 — ценовой ход без выбора строки по иной причине.

  На test без пула 26: корзина 17, сильная фраза 2, не цена 6, иное 1. Поэтому строка «список услуг» сейчас описывает
  только списки, дошедшие до выбора строки (13 из 95 на dev), а не путь корзины.
- **«В словаре» ниже «вне словаря» — эффект отбора, не слабость словаря.** Слова из словаря клиники чаще решает
  сильная фраза: они до LLM не доходят. До выбора строки доходят трудные случаи словаря.
- **Промах пула почти всегда честный.** На dev 32 вопроса с пулом без эталона даже после 2-го круга: 28 без цены,
  1 список с нужной, 1 одна цена вместо списка, 1 чужая, 1 список без нужной. Эталона вне прайса мира среди них нет.
  Потолок выбора здесь — сборка кандидатов, а не LLM.
  - в словаре: g0047, g0174, g0292, g0381, g0395, g0572, g0612, r0046, r0071;
  - вне словаря: g0043, g0150, g0196, g0225, g0262, g0274, g0329, g0372, g0398, g0400, g0419, g0445, g0499, g0677, r0151;
  - списки: g0254, g0255, g0354, g0428, g0622, g0641, r0098, r0101;
  - test: g0829 (в словаре), g0812 (вне), g0851 (список).
- **Выборка маленькая.** test — 21 вопрос с пулом; один вопрос ≈ 5 п. п. Решения — по dev и по поимённым переходам
  карточки, test — один раз на решение «катить / не катить».

## Как пользоваться (до/после снятия выключателей 27–28.10)

```bash
./venv/bin/python -m evalbench.run --set ~/Dev/dla-private/golden_v1.jsonl --set ~/Dev/dla-private/golden_v1_random.jsonl \
    --split dev --code-root <дерево> --world 20261008 --profile day --mode cached --name <имя>_dev <--cfg из run.json d15_all_dev>
./venv/bin/python -m evalbench.card rp_6883d19_dev <имя>_dev
```

Сравнивать с `rp_6883d19_*` (не с `d15_all_*`: там пула нет — карточка честно пишет «пул не записан»). Дерево кода для
«после» должно включать `c38e7ed`: без записи пула замера нет. Режим down тоже пишет пул 1-го круга (он пишется до
вызова LLM), но второго круга в нём нет.
