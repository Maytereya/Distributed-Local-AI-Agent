# Просьба клинике: памятки подготовки в справочник МИС (02.10.2026)

Решение владельца 02.10: на вопросы «как подготовиться к …» бот будет отвечать только по
памяткам МИС — поле «Подготовка» в карточке услуги (`serviceInfo`). Базу знаний (скрипты
операторов) для подготовки бот использовать не будет: в ней много внутренних указаний
администраторам (куда записывать, что говорить), и пациент не должен их видеть.

Ниже — процедуры, по которым подготовка сейчас есть только в базе знаний, а в МИС её нет.
Пока клиника не заполнит МИС, на вопрос о подготовке к ним бот предложит оператора.

**Как заполнять:** текст — для пациента (что сделать, когда, чего избегать, что взять с
собой), без указаний администратору. В том же поле синонимов карточки (`serviceSynonyms`)
стоит указать, как пациенты называют процедуру (колонка «Синонимы»): бот их читает.

## 1. Карточка услуги в МИС есть, памятки нет — вписать готовую памятку

| Эзофагогастродуоденоскопия (ФГДС) | 30.1.1.1 | «ПАМЯТКА Гастроскопия (без наркоза)», «ПАМЯТКА Гастроскопия с наркозом» | гастроскопия, ЭГДС |
| Тотальная фиброколоноскопия (ФКС) | 30.1.2.1 | «ПАМЯТКА ФКС без наркоза», «ПАМЯТКА ФКС с наркозом» | колоноскопия |

Вопрос к клинике: памятку «ФКС + ФГДС с наркозом» к какой услуге привязать (отдельной
комбинированной услуги в прайсе нет), и где хранить варианты «с наркозом / без наркоза» —
двумя абзацами в одной памятке или отдельными услугами.

## 3. Уже есть в МИС — ничего делать не нужно

«Сдача крови на холестерин» — в МИС памятки есть у «Липидограммы», «Холестерола» и ещё 9
услуг.

## 4. Не про подготовку

«Алгоритм консультации по услуге Вызов на дом специалиста», «Скрипт по записи ЛОР по
акции», «Инструкция для администраторов» (4 части), «Набор аллергенов для постановки
накожных проб», «Справка для налоговой» — к подготовке не относятся.
