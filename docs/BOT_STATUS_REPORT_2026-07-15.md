## 5. План commercial-offer (мульти-подсчёт анализов) — РАЗДЕЛ АГЕНТА + факты

**Живой прогон эндпоинта (VPN):** `POST /api/v1/site/commercial-offer`
`{"services":[serviceId...],"region":3}` → **200, `application/pdf` (~55KB)** — готовая
PDF-оферта, НЕ JSON с суммой. `[неизвестный id]` → 404 «Для выбранных услуг
отсутствуют актуальные цены». GET не поддерживается.

Следствие для дизайна: сумму мульти-анализа **считаем сами** из прайса
(`load_price_by_region(3)`: serviceId→cost), текстом («Гепатит C — X₽, ВИЧ — Y₽,
итого N₽»); PDF-оферту прикладываем документом (attachment) опционально.
