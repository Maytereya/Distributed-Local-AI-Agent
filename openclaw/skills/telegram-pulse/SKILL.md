name: telegram-pulse
description: Доступность Telegram API, покрытие наблюдений и пропуски измерений.
---

Команда `/telegram_pulse` обслуживается плагином `ai-server-monitor` без LLM.
Для свободного запроса используй `ai_server_telegram_pulse_report`, если
инструмент доступен сессии. Передай готовый текст без пересказа или расчёта
собственных процентов. Доступность API не доказывает доставку сообщения.
Два входа sing-box не являются независимыми внешними маршрутами.
При ошибке сообщи о временной недоступности мониторинга.

Для отчёта не нужны токены, shell, Docker или чтение файлов конфигурации.
