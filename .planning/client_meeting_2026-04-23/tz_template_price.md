> **Инструкция для заполняющего:**

## 1. Что делает функция

Пациент спрашивает, сколько стоит приём у конкретного специалиста (кардиолога, уролога, лора и т. д.) — бот показывает цену и перечисляет врачей, которые его ведут.

---

## 2. Как пациент может спросить

Примеры фраз, на которые функция должна срабатывать:

- «Сколько стоит приём кардиолога?»
- «Цена консультации уролога»
- «Сколько возьмёте за осмотр у лора?»
- «Почём приём у эндокринолога?»
- «Стоимость терапевта»
- «Сколько стоит сходить к гинекологу?»

## 3. Как бот должен ответить (шаблон ответа)

**Пример работающего ответа:**

> По услуге «приём кардиолога» нашёл следующее:
>
> 1) Розничная цена: Приём (осмотр, консультация) врача-кардиолога первичный — **3 000 руб.** Формат: поликлиника. Адрес: г. Самара, пр. Ленина, 5.
>
> 2) Врачи (по приоритету):
> 1. Михлик Ирина Владимировна (Кардиолог) — 3 000 руб.; доступен, ближайшее окно 22.04 09:30.
> 2. Хальметова Алина Алексеевна (Кардиолог) — 3 000 руб.; доступен, ближайшее окно 25.04 13:30.
> 3. Чичкин Максим Олегович (Кардиолог) — 3 000 руб.; расписание не найдено.
>
> Если нужно, покажу подробное расписание любого из этих врачей.

**Что клиника должна решить по этому шаблону:**

| Вопрос | Ответ клиники |
|---|---|
| Показывать ли цену первичного и повторного приёма вместе? | *(да / только первичный / только то, что спросил пациент)* |
| Сколько врачей показывать максимум? | *(сейчас 4; можно изменить)* |
| Нужно ли показывать адрес филиала в каждом ответе? | *(да / нет / только если филиалов несколько)* |
| Нужно ли показывать «ближайшее окно» каждого врача? | *(да / нет)* |
| Последняя фраза («Если нужно, покажу...») — подходит? | *(да / изменить на: ...)* |

## 4. Если что-то необычное — как бот должен себя вести

| Ситуация | Что должен ответить бот |
|---|---|
| Специалиста вообще нет в клинике (например, «гастроэнтеролог» не принимает) | «К сожалению, в данный момент клиника не оказывает данную услугу.» |
| Специалист есть, но цена в базе не указана | «Цена на приём уточняется, передам ваш запрос оператору.» → оператор |
| Пациент спрашивает «подешевле» или «самый дешёвый кардиолог» | *(заполнить: что говорим? сортируем по цене? или "у всех одинаковая"?)* |
| Пациент спрашивает про приём **по ДМС** | *(заполнить: отвечаем текстом? сразу оператор?)* |
| Пациент спрашивает про приём **для ребёнка** | *(заполнить: ищем детского специалиста? или подключаем оператора?)* |
| Пациент спрашивает про приём **на дому** | *(заполнить)* |
| Пациент спрашивает про **повторный** приём | *(заполнить: сразу цена повторного? или уточняем?)* |
| Запрос слишком общий: «сколько стоит приём?» (без специальности) | *(заполнить: уточняем «к какому специалисту?» — какой текст?)* |
| Пациент называет редкого специалиста, которого точно нет | *(см. первую строку — тот же ответ?)* |
