# Функционал бота

## Финальное ТЗ

Только для Самары.

1. Получение результатов анализов.
2. Получение информации о стоимости анализов.
3. Получение информации о медицинской услуге с учетом только розничного прайса. Выводим первых 4х врачей по рейтингу и доступности расписания. Добавляем подготовку к услуге, если имеется.
4. Получение информации о конкретном враче по ФИО с розничным прайсом.
5. Получение информации о врачах выбранной специальности с учетом рейтинга.
6. Получение расписания врача по ФИО.
7. Выполнение записи к врачу по ФИО.
8. Получение справки в налоговую.

## Актуальный функционал бота

Бот сейчас работает только по Самаре. Если пользователь пишет по другому городу, диалог переводится на оператора.

### 1. Получение результатов анализов

Бот умеет проверять готовность результата анализа и формировать ссылку на результат, если пользователь передал достаточно данных.

Пример запроса:
`Проверьте, готов ли результат анализа. Иванов, 1989, Бг, 1234`

Пример ответа бота:
`Сформировал ссылку для просмотра результата по указанным данным.`

Если данных не хватает, бот сам уточняет фамилию, год рождения, код анализа и номер анализа.

### 2. Получение стоимости анализов

Бот умеет сообщать стоимость анализов и услуг по Самаре.

Пример запроса:
`Сколько стоит общий анализ крови?`

Пример ответа бота:
`Нашёл стоимость по вашему запросу.`

Если запрос слишком общий, бот просит уточнить услугу.

Пример:
`Сколько стоит УЗИ?`

Типовой ответ:
`Введите конкретное название процедуры, например: стоимость УЗИ брюшной полости или цена УЗИ молочной железы.`

### 3. Информация о медицинской услуге

Бот умеет показывать информацию по услуге: розничную цену, подходящих врачей и подготовку, если пользователь спрашивает о ней явно.

Пример запроса:
`Сколько стоит УЗИ брюшной полости и как подготовиться?`

Пример ответа бота:
`По услуге найдено: розничная цена, подходящие врачи и правила подготовки.`

По таким запросам бот:
- показывает розничную цену;
- выводит до 4 подходящих врачей;
- учитывает приоритет врачей и наличие ближайших свободных окон;
- добавляет подготовку, если она найдена.

### 4. Информация о конкретном враче по ФИО

Бот умеет находить конкретного врача по фамилии или ФИО, показывать его специализацию, адреса приёма и примеры стоимости услуг у этого врача.

Пример запроса:
`Расскажите про врача Дразнина`

Пример ответа бота:
`Нашёл врача, его специализацию, адреса приёма и примеры стоимости услуг у этого врача.`

### 5. Информация о врачах выбранной специальности

Бот умеет подбирать врачей по специальности и выводить их списком в приоритетном порядке.

Пример запроса:
`Какие кардиологи принимают?`

Пример ответа бота:
`Нашёл врачей по этой специальности. Если нужно, могу показать расписание любого из них или помочь с записью.`

### 6. Расписание врача по ФИО

Бот умеет показывать расписание конкретного врача.

Пример запроса:
`Покажите расписание Дразнина`

Пример ответа бота:
`Нашёл расписание: филиал, даты и свободные окна.`

Если фамилия врача не указана, бот просит уточнение.

### 7. Запись к врачу по ФИО

Бот умеет вести пользователя по сценарию записи: уточнять врача, филиал, дату, время и ФИО пациента.

Пример запроса:
`Запишите меня к Дразнину на завтра после 15:00`

Типовой сценарий ответа бота:
1. Бот предлагает подходящий филиал или показывает расписание.
2. Бот уточняет дату и время.
3. Бот просит ФИО пациента.
4. Бот показывает итог записи и просит подтверждение.
5. После подтверждения бот передаёт заявку оператору.

Типовой финальный ответ:
`Передаю заявку оператору для окончательного подтверждения записи.`

Важно: на текущий момент бот не завершает запись полностью самостоятельно, а собирает данные и передаёт заявку оператору.

### 8. Получение справки в налоговую

Бот умеет подсказывать, как оформить справку для налогового вычета.

Пример запроса:
`Как получить справку для налогового вычета?`

Пример ответа бота:
`Заказ справки на налоговый вычет осуществляется на сайте https://naykalab.ru/spravka-nalogoviy-vichet`

## Что важно учитывать

- Бот работает только по Самаре.
- Если вопрос выходит за рамки доступных данных или сценарий нельзя безопасно завершить автоматически, бот переводит диалог на оператора.
- Подготовка к анализам и процедурам поддерживается как отдельный сценарий и может дополнять ответы по услугам.
- По записи бот сейчас работает как помощник по сбору данных, а не как полностью автономная запись без участия оператора.
